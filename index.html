Data notes

67 point records from commissioned local surveys. Elevations use meters relative to Georgetown Datum (mGD). The shapefile geometry is WGS 84 (EPSG:4326). Missing attributes are shown as “Not recorded.”

Some field observations flag measurements for confirmation. Map markers indicate surveyed structure locations, not individual gate openings.

Source: Region 4 drainage gate inventory. Refer to the accompanying HydroShare README for provenance and limitations.
